# TruthLens AI 🔍
### Intelligent Fake Job Detection Platform
**Python · Machine Learning · NLP · FastAPI · HTML/CSS · Render**

TruthLens AI is a Machine Learning-powered web application engineered to identify potentially fraudulent job postings. By combining Natural Language Processing, feature engineering, and predictive modelling, the platform helps job seekers distinguish between genuine employment opportunities and suspicious recruitment advertisements.


## 🌟 The Problem & The Solution

**The Challenge:**

Online recruitment has made job searching more accessible, but it has also created opportunities for fraudulent job advertisements. Fake recruiters, misleading company profiles, suspicious job descriptions, and unrealistic employment offers can deceive job seekers and put their personal information at risk.

Identifying these fraudulent listings manually is difficult, especially when suspicious advertisements appear similar to genuine opportunities.

**The Solution:**

TruthLens AI provides an intelligent job-posting analysis platform that uses Machine Learning to classify job advertisements as **Genuine or Fraudulent**.

Users can enter job-related information through an interactive web interface and receive a prediction generated by a trained classification model.

The goal is simple: make online job searching more informed, secure, and reliable through Artificial Intelligence.

## 🧠 Machine Learning Pipeline

The intelligence behind TruthLens AI is built around a structured data preprocessing and classification workflow.

**1. Data Collection**

The project uses the Fake Job Postings dataset containing genuine and fraudulent employment advertisements.

**2. Data Preprocessing**

- Handling missing values
- Cleaning and preparing textual information
- Combining relevant text columns
- Preparing categorical and numerical features

**3. Feature Engineering**

Relevant textual information such as job titles and company profiles is combined to create meaningful text features for model training.

**4. NLP & Text Vectorization**

CountVectorizer transforms textual information into numerical feature representations that can be processed by Machine Learning algorithms.

**5. Categorical Encoding**

OneHotEncoder converts categorical variables into numerical representations while handling previously unseen categories.

**6. Feature Transformation**

ColumnTransformer combines text, categorical, and numerical preprocessing into a unified feature-processing pipeline.

**7. Model Training & Prediction**

The trained classification model processes the transformed job information and generates a prediction.

## 🛠️ Installation & Quickstart

### Prerequisites

- Python 3.10 or compatible version
- pip package manager
- Git
- Recommended: Virtual environment

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
cd TruthLens-AI
```

### Step 2: Create a Virtual Environment

```bash
python -m venv .venv
```

### Step 3: Activate the Environment

For Windows:

```bash
.venv\Scripts\activate
```

### Step 4: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 5: Launch the Application

```bash
uvicorn app:app --reload
```

Open your browser:

```text
http://127.0.0.1:8000/
```

## 🛡️ Responsible Use

TruthLens AI is designed as an assistive fraud-detection tool.

- Predictions should be treated as indicators, not absolute verification.
- A genuine job posting may occasionally be classified incorrectly.
- A fraudulent posting may not always be detected.
- Users should independently verify recruiters and employers before sharing personal information or making payments.

The platform does not guarantee the legitimacy of any job advertisement.
